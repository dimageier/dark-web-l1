# Dark Web — Level 1: The 3-Hour Podcast

Playable satire platformer/podcast build. Collect Sources and The Receipts, dodge podcast hazards, then log off through the sauna door.

Play on GitHub Pages: https://dimageier.github.io/dark-web-l1/

Play via jsDelivr: https://cdn.jsdelivr.net/gh/dimageier/dark-web-l1@main/index.html?v=podcast

The standalone game is delivered from the root `index.html`; the fallback deployment uses a seven-part gzip loader (`c0.txt`–`c6.txt`) when GitHub file-update limits prevent the single-file upload.

## Controls

- Arrow keys or A/D: move
- Space or Up: jump
- Down + Space: drop through shelves
- P: pause, R: restart, M: mute

Parody only — no real likenesses, logos, or quotes.
