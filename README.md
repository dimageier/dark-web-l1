# Dark Web — Level 1: Noise (playable stub)

Henry's House–style short-room platformer stub. Survive Infowars HQ noise: slide under tickers, climb the Breaking Stack, mute shout bubbles on quiet pads.

## Play online

After GitHub Pages is enabled: https://dimageier.github.io/dark-web-l1/

## Open locally

```bash
cd dark-web-l1
python3 -m http.server 8765
```

Then open http://localhost:8765/

Or open `index.html` directly in a modern browser.

## Controls

| Key | Action |
|-----|--------|
| ←→ / A D | Move |
| ↑ / W | Jump |
| Shift or ↓ / S | Slide (under tickers) |
| Space | Mute (3 charges; Facts refill) |
| Enter / Click | Start / restart after win |

## Rooms

1. **Lobby Crawl** — slide under the orange ticker, grab Fact Cards, reach EXIT
2. **Breaking Stack** — climb; every ~4s BREAKING flash drops marked platforms
3. **Studio — Megaphone** — stand on QUIET pads, Mute near bubbles, bank 3 clips → win overlay
